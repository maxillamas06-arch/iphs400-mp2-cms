# CMS field notes — WordPress Playground

1. **Quick Draft:** I wrote a quick post saying "Rayados beat Pumas 2-1" and saved it as a draft. I thought it might show up on the website, but it didn't. This makes sense because sometimes you want to work on a post before everyone can see it. For my fan club, this would help me prepare news before posting it.

2. **Publishing the post:** After I clicked Publish, my post appeared on the website above the Hello World post. I also noticed that the text was not perfectly aligned with the title, which looked a little weird. For my fan club, I would need to check how posts look after publishing them.

3. **Creating a page:** I created a page called "Next Matches" and it automatically appeared in the top menu. What surprised me was that regular posts don't appear there. I think this is useful because I could have pages for important information and posts for regular news and updates.

4. **Page URL:** When I checked the URL, I noticed that WordPress automatically used the page title to create `/next-matches/`. This made sense and I think it's useful because fans could easily find and share different pages.

5. **Footer:** I noticed that even after creating a new page, the footer links stayed exactly the same. I thought they might update automatically like the top menu, but they didn't. For my fan club, I would probably need to edit the footer separately if I wanted to add more links.

6. **Creating a user:** I created a new user called fan1 and gave them the Editor role. I also noticed that WordPress showed the password strength as Medium and allowed the admin to change user roles. This would be useful for my fan club because I could have other people helping me manage the website.

7. **Logging in as an Editor:** When I logged in as juan perez, I noticed that several options disappeared from the menu, like Plugins, Users, and Settings. At first I was surprised, but it makes sense because an Editor shouldn't have the same control as an admin. For my fan club, this would allow people to help with posts without changing important website settings.

8. **Update notice:** Another thing I noticed was that the update message changed. As an admin, I could update WordPress, but as an Editor, it only told me to contact the administrator. This makes sense because only certain users should be able to make big changes to the website.

9. **Trying to access Users:** I tried typing `/wp-admin/users.php` directly while logged in as an Editor, but WordPress didn't let me access it. I thought maybe typing the URL would work, but it still blocked me. This showed me that WordPress actually protects admin features, which is important for keeping my fan club website secure.
